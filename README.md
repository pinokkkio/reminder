# Telegram-бот напоминаний (serverless)

Бот, которому можно написать «завтра в 10:30 позвонить маме» или «каждый понедельник в 9 планёрка» —
и он напомнит в нужное время. Есть мини-приложение внутри Telegram для создания и удаления напоминаний.

**Стек:** Cloudflare Workers + D1 (SQLite) + Cron Triggers. Никаких серверов, всё укладывается
в бесплатный тариф Cloudflare (100 тыс. запросов в день, cron раз в минуту, 5 ГБ D1).

```
Telegram ──webhook──▶ Worker /webhook ──▶ D1 (reminders)
Mini App ──/api/*───▶ Worker            ▲
Cron (каждую минуту) ▶ Worker.scheduled ┘──▶ sendMessage
```

## Возможности

- Разбор естественного русского языка:
  - `завтра в 10:30 …`, `послезавтра …`, `сегодня в 7 вечера …`
  - `25 декабря в 18:00 …`, `05.11 в 12:15 …`, `2027-01-02 …`
  - `через 2 часа …`, `через полчаса …`, `через 3 дня в 15:00 …`
  - `в пятницу в 19 …`, `вечером …`, `в полдень …`
- Повторы:
  - `каждый день в 9:00 …`, `ежедневно …`, `ежемесячно …`
  - `по будням в 8:30 …`, `по выходным …`
  - `каждый понедельник и четверг в 20:00 …`, `по средам …`
  - `каждые 3 часа …`, `каждые 2 недели …`
  - `каждый месяц 15 числа …` (31-е → последний день короткого месяца), `каждый год 1 марта …`
- Кнопки под напоминанием: «⏰ 10 мин», «1 час», «Завтра», «🔕 Больше не напоминать».
- `/list` — список с кнопками удаления, `/tz` — часовой пояс пользователя (по умолчанию `Europe/Moscow`).
- Корректная работа с часовыми поясами и переходом на летнее время.
- Мини-приложение: ввод текстом или через форму (дата, время, повтор, дни недели, свой интервал),
  список и удаление. Запросы авторизуются подписью `initData` от Telegram.
- Работает и в группах: там бот реагирует только на сообщения, начинающиеся с «напомни».

## Развёртывание

Понадобятся Node.js 20+ и бесплатный аккаунт Cloudflare.

1. **Создайте бота** у [@BotFather](https://t.me/BotFather) (`/newbot`) и сохраните токен.

2. **Установите зависимости и войдите в Cloudflare:**
   ```bash
   npm install
   npx wrangler login
   ```

3. **Создайте базу D1** и впишите её `database_id` в `wrangler.toml`:
   ```bash
   npx wrangler d1 create reminder-db
   npm run db:migrate
   ```

4. **Задайте секреты:**
   ```bash
   npx wrangler secret put BOT_TOKEN        # токен от BotFather
   npx wrangler secret put WEBHOOK_SECRET   # любая случайная строка из A-Z, a-z, 0-9, _ и -
   ```

5. **Задеплойте:**
   ```bash
   npm run deploy
   ```
   Wrangler выведет адрес вида `https://telegram-reminder-bot.<ваш-поддомен>.workers.dev`.

6. **Подключите бота** — откройте в браузере один раз:
   ```
   https://telegram-reminder-bot.<ваш-поддомен>.workers.dev/setup?key=<WEBHOOK_SECRET>
   ```
   Это зарегистрирует вебхук, команды и кнопку меню «Напоминания», открывающую мини-приложение.

7. Напишите боту `/start`. Готово.

> Чтобы мини-приложение было доступно и по прямой ссылке `t.me/<bot>/app`, в @BotFather выполните
> `/newapp` и укажите URL `https://…workers.dev/app`. Для работы через кнопку меню это не обязательно.

### Автодеплой из GitHub (необязательно)

Workflow `.github/workflows/deploy.yml` деплоит при пуше в `main`. Включите его:
добавьте секреты репозитория `CLOUDFLARE_API_TOKEN` (шаблон токена «Edit Cloudflare Workers» + права на D1)
и `CLOUDFLARE_ACCOUNT_ID`, а также переменную `DEPLOY_ENABLED=true`.

## Локальная разработка

```bash
cp .dev.vars.example .dev.vars    # впишите токен тестового бота
npm run db:migrate:local
npm run dev                       # http://localhost:8787
npm test                          # тесты парсера, повторов, подписи initData
npm run typecheck
```

Для проверки cron локально: `npx wrangler dev --test-scheduled`, затем
`curl "http://localhost:8787/__scheduled?cron=*+*+*+*+*"`.

## Структура

| Файл | Назначение |
|---|---|
| `src/index.ts` | Точка входа: роутинг HTTP (`/webhook`, `/setup`, `/app`, `/api/*`) и cron |
| `src/bot.ts` | Команды, обработка сообщений и кнопок, отправка напоминаний |
| `src/parser.ts` | Разбор русского текста в дату/время/правило повтора |
| `src/repeat.ts` | Правила повтора и расчёт следующего срабатывания |
| `src/time.ts` | Часовые пояса через `Intl`, без внешних библиотек |
| `src/scheduler.ts` | Ежеминутная рассылка наступивших напоминаний |
| `src/api.ts` | REST API мини-приложения |
| `src/auth.ts` | Проверка подписи `initData` |
| `src/miniapp.ts` | HTML мини-приложения |
| `migrations/` | Схема D1 |

## Ограничения

- Точность — до минуты (cron срабатывает раз в минуту).
- Не более 200 активных напоминаний на чат.
- Сработавшие разовые напоминания хранятся 30 дней (чтобы работала кнопка «Отложить»), затем удаляются.
